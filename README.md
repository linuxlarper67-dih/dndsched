# DND Scheduler
Pick days + hours (up to 30 entries) when Do Not Disturb turns on/off. Material You, no root.

## Build on GitHub
1. Create a repo, upload everything in this folder (keep `.github`).
2. Actions tab -> "Build APK" -> run (or just push).
3. Open the finished run -> Artifacts -> DndScheduler-apk -> install the APK.

First launch: tap "Open settings" and allow Do Not Disturb access.
